# Redevelopment execution record

This document records the scope and evidence expected for the redevelopment. Current deployment state, owner decisions, and operating receipts are maintained in access-controlled release records.

## Site experience

The experience scope covers personal context, writing, work, independent interests, career history, and contact routes while preserving article history and retired intake behavior. The acceptance matrix defines the required routes and content behavior.

## Release qualification

Release verification checks the built artifact identity, canonical routes, preserved article identities, and public readback. A local build or automated gate does not establish that a release is serving publicly.

## Background operation

Background maintenance is a separate capability with its own source-authority, provider-limit, review, recovery, public-readback, and publisher-cutover requirements.

Exact account and resource details, private integration design, and operational receipts belong in access-controlled records rather than this public execution note.
