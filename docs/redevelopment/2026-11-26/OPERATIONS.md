# Background maintenance boundary

Background maintenance is independent of the visitor-facing site. The site should continue serving its last verified static content when background services are unavailable.

Account-specific operating procedures belong in access-controlled records. Protect credentials, raw memory, client information, and private publication details.

A production resume binds a fresh retirement observation to the current paused writer epoch. The operator verifies that the previous writer has stopped and reconciles any unfinished publication before authorizing the transfer. The resume transition and its receipt are recorded together. Check the current control state and receipt before retrying an ambiguous result.

Verify provider and publishing access before retiring the previous writer. The production resume rejects missing credentials or invalid policy, pricing, and repository settings with `RUNTIME_NOT_READY` and preserves the paused epoch. The configuration check makes no external calls. After correcting the configuration, obtain a fresh retirement observation before retrying.

Production uses an hourly UTC Cron trigger. Configure Chicago slots on the hour and allow at least two model calls per candidate for drafting and independent review. The render step checks these settings before deployment. Spend ceilings and request size limits still apply to each candidate.
