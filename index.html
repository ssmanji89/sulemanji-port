Operating commitments

Three rules that survive the domain change.

01

Live state over narrative

A recommendation, ticket note, or agent response is not proof that the external system changed. Check the authority.

02

Risky actions stay reviewable

Preview the write, name the boundary, preserve the evidence, and verify the effect after execution.

03

One-off fixes should leave leverage

Turn the incident into a script, runbook, interface, test, or reusable pattern so the same pain does not invoice twice.
